# Assignment 1 - Personal Portfolio

Simple, responsive personal portfolio built with HTML, CSS, and JavaScript. It includes an About section, Projects section, and Contact form, plus a small JavaScript interaction for smooth scrolling and a time-based greeting.

## Project Structure

- `index.html` - Main page
- `css/styles.css` - Styling and responsive layout
- `js/script.js` - JavaScript interactions
- `assets/images/` - Placeholder images
- `docs/ai-usage-report.md` - AI usage documentation
- `docs/technical-documentation.md` - Technical notes

## Setup Instructions

1. Clone or download this repository.
2. Open `index.html` in your browser.

No build tools or dependencies are required.

## AI Usage Summary

AI assistance was used for layout planning, content drafting, and documentation wording. Full details are in `docs/ai-usage-report.md`.
