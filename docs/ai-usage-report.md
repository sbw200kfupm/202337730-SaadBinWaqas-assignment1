# AI Usage Report

## Tools Used & Use Cases

- ChatGPT (Codex)
  - Drafted the initial HTML structure and suggested section layout.
  - Helped outline the CSS styling approach and responsive breakpoints.
  - Assisted with documentation wording for the README and technical notes.

## Benefits & Challenges

- Benefits
  - Faster drafting of layout ideas and consistent wording.
  - Quick checks for missing requirements (sections, responsiveness, and JS).
- Challenges
  - Some suggestions were too detailed for a simple assignment, so I had to
    simplify and keep the design basic so I could write code I can understand. 

## Learning Outcomes

- Reinforced how to build a clean HTML structure with semantic sections.
- Improved understanding of responsive grids and reusable CSS classes.
- Practiced adding small JavaScript enhancements without overcomplicating the site.

## Responsible Use & Modifications

- Reviewed all AI generated content and simplified where necessary.
- Adjusted text, class names, and layout to match the assignment requirements.
- Verified that the code is original, understandable, and properly organized.
