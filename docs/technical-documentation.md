# Technical Documentation

## Overview

This project is a simple, responsive personal portfolio built with plain HTML,
CSS, and JavaScript. It is structured for clarity and easy expansion in later
assignments.

## Structure

- `index.html` contains the layout and semantic sections (About, Projects, Contact).
- `css/styles.css` defines the visual design, grid layout, and responsive rules.
- `js/script.js` handles smooth scrolling, the time-based greeting, and the live year.
- `assets/images/` stores lightweight SVG placeholders.

## Responsive Design

- Desktop: two-column layouts for the hero and contact sections.
- Tablet/Mobile: single-column layouts via a 900px breakpoint.
- Small screens: stacked buttons and footer alignment adjustments at 600px.

## JavaScript Features

- Time-based greeting in the About section.
- Smooth scrolling for in page navigation links.
- Dynamic year display in the Contact section.

## Accessibility Notes

- Skip link added for keyboard users.
- Clear focus styles on form inputs.
- Descriptive alt text for all images.

## Testing

- Manually tested by resizing the browser window to confirm layout changes.
- Checked form fields for required validation and basic usability.
